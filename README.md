# Frequency Shift

Kamu duduk di kabin mobil dengan radio tua di tangan. Dari frekuensi yang seharusnya tidak ada, seseorang meminta tolong. Cari frekuensinya, pahami sandi morse-nya, dan jangan sampai lengah.

Game horor bergaya PSX, dibuat untuk [Game Off 2026](https://itch.io/jam/game-off-2026) dengan tema **SHIFT**.

Game bisa dimainkan di Android dan PC lewat itch.io: [link halaman itch.io]

> Mengandung unsur horor. Disarankan memakai headset.

## Tema SHIFT

Tema SHIFT diterjemahkan lewat pergeseran frekuensi radio. Sinyal yang kamu cari hanya bisa ditemukan dengan menggeser tuning ke frekuensi yang tepat, dan keadaan sekitar ikut berubah saat kamu lengah.

## Fitur

- Sistem radio: cari frekuensi, tahan sinyal, lalu kirim pesan morse
- Mekanik morse: masukkan kode untuk mengirim koordinat dan pesan kepada Ranger
- Anomali suara dan visual yang muncul secara acak
- Pergantian bahasa bisa dilakukan di Pengaturan –> Kontrol –> Pilih bahasa Indonesia atau English.

## Kontrol

| Tombol | Fungsi |
| **Interact atau E** | Ambil dan letakkan radio |
| **Tombol ↑ / ↓** | Geser tuning frekuensi |
| **Morse atau Shift** | Tekan dan tahan untuk titik (pendek) atau garis (panjang) |
| **Eye atau Spasi** | Tahan untuk menutup mata |

## Cara membuka project

**Kebutuhan:**
- Godot **4.7.2** (renderer Compatibility)

**Langkah:**
1. Clone repo ini: `git clone https://github.com/Fikriabdulmughni/frequency-shift.git`
2. Buka Godot, pilih **Import**, lalu pilih file `project.godot` di folder hasil clone.
3. Tunggu Godot mengimpor semua asset.
