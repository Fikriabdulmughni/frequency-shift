# Frequency Shift

You sit in a car cabin with an old radio in your hands. From a frequency that shouldn't exist, someone is asking for help. Find the signal, decode the morse, and don't let your guard down.

A PSX-style horror game made for [Game Off 2026](https://itch.io/jam/game-off-2026) with the theme **SHIFT**.

The game can be played on Android and through itch.io: (https://violettebdg.itch.io/frequency-shift)
> Contains horror elements. Headphones are recommended.

## SHIFT Theme

The SHIFT theme is interpreted through radio frequency shifting. The signal you're looking for can only be found by turning the tuning to the right frequency, and the surroundings change when you let your guard down.

## Features

- Radio system: search for frequencies, hold the signal, then send morse messages
- Morse mechanic: enter codes to send coordinates and messages to the Ranger
- Randomly appearing sound and visual anomalies
- Language can be changed in Settings → Controls → choose Indonesian or English.

## Controls

| Button | Function |
|---|---|
| **Interact** | Pick up and put down the radio |
| **↑ / ↓ buttons** | Adjust the frequency tuning |
| **Morse** | Press and hold for a dot (short) or a dash (long) |
| **Eye** | Hold to close your eyes |

## How to Open the Project

**Requirements:**
- Godot **4.7.2** (Compatibility renderer)

**Steps:**
1. Clone this repo: `git clone https://github.com/Fikriabdulmughni/frequency-shift.git`
2. Open Godot, choose **Import**, then select the `project.godot` file in the cloned folder.
3. Wait for Godot to import all assets.
